# 3회차 C2 (음성 존재·사전 SNR 과대 추정) 진행 기록, 기준 r03-base-s2

## C2-0. 음성 존재 판정 상한 (`presence/`, `tools/diagnose_presence.py`, 부분집합 350개)

현재 출력에서 "음성 없음"으로 판정한 칸(저역 제외)에 추가 감쇠를 곱했다. 현재 출력은 2.029다.

| 판정 | −10 dB | −20 dB | −40 dB | 정밀도 | 재현율 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 프레임 오라클 (깨끗한 음성 −40 dB 기준) | 2.029 | 2.015 | 1.981 | | |
| 칸 오라클 (−30 dB 기준) | 2.000 | 1.664 | 1.335 | | |
| YIN 유성 ±100 ms | 1.909 | 1.455 | 1.181 | 0.87 | 0.39 |
| 사후 SNR > 3 dB | 2.002 | 1.935 | 1.828 | 0.95 | 0.90 |
| YIN 또는 사후 SNR 3 dB | 2.006 | 1.948 | 1.857 | 0.95 | 0.91 |

- 3초 클립의 91 %가 음성 프레임이라, 프레임 단위 게이팅으로는 얻을 것이 없다.
- 칸 단위로 이진 판정해서 감쇠하면 오라클이어도 크게 손해다. 약한 음성 성분까지 함께 지워지기 때문이다.
- 따라서 C0의 3.15는 칸을 지워서 나온 값이 아니다. 잡음 우세 칸의 사전 SNR을 연속값으로 정확히 맞혀서 나온 값이다.

## C0 보강. DD 오차 방향 (`../20261117-r03-c0/xi/`, 부분집합)

| 사전 SNR | 현재 하한 | 하한 없음 |
| --- | ---: | ---: |
| DD | 2.029 | 1.999 |
| 과대 추정만 참값으로 교정 (min(DD, 참값)) | 2.315 | **2.713** |
| 과소 추정만 교정 (max(DD, 참값)) | 2.256 | 2.339 |
| +6 dB 넘는 과대 추정만 자름 | 2.274 | 2.498 |

- 과대 추정 교정의 이득은 거의 모든 종류에서 나온다 (광대역 +0.90, HF +0.99, 경보 +1.03).
- 예외는 vehicle_interior와 phone_dialing이다.

## C2-1. 실현 가능한 과대 추정 억제 (`subset/`, 부분집합 21개 후보)

| 후보 | 부분집합 PESQ-WB | 기준 대비 |
| --- | ---: | ---: |
| 기준 (DD 정·역방향 평균, 현재 하한) | 2.0294 | 0 |
| 관측 기반 사전 SNR 상한 k 4, 최소 −20 dB | 2.0209 | −0.009 |
| 정·역방향 기하평균 | 2.0121 | −0.017 |
| 평균 + 하한 −30 dB | 2.0105 | −0.019 |
| 정·역방향 최소 | 1.9339 | −0.096 |
| 사전 SNR 상한 + 하한 −25 dB (최고) | 1.9969 | −0.033 |

- **미채택.** 21개 후보가 모두 기준보다 낮다.
- 관측(γ)만 보고 사전 SNR을 낮추면, 잡음 칸과 함께 약한 음성 칸도 같이 깎인다.
- 오라클 교정(+0.68)과 실제 결과(−0.01)의 차이는 "이 칸의 에너지가 음성인지 잡음인지"를 관측 통계로 구분할 수 없다는 것을 보여 준다.
- 스위치(`dd_combine`, `xi_cap_k`, `xi_cap_min_db`)는 기본값 끔으로 남긴다.
