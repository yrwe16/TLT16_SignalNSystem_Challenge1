# +0.4 탐색 (기준 r03-base-s4, Train 부분집합 350개, 분석만)

부분집합 기준 점수는 2.626이다. 측정 스크립트는 저장소 밖 임시 파일이고, 결과는 이 폴더의 CSV에 있다.

## 1. 출력 후처리 (`post_levers_subset.csv`)
- 700 Hz 셸프 위에 대역을 추가로 감쇠하면 모두 손해였다.
  - 1.5k/2.5k/4k 위 −5 dB: −0.02 ~ −0.03
  - 300 Hz 아래 −5 dB: −0.055
  - 300–700 Hz −5 dB: −0.13
- 프레임 게이팅(무음 구간 감쇠)은 실제 VAD로 −0.14 ~ +0.002, 정답 VAD로도 +0.001 ~ −0.03이었다. **무음 구간에는 개선 여지가 없다.**

## 2. 정답 대입 상한 (`oracle_bands_subset.csv`)
정답 IRM에 셸프를 곱한 출력을 특정 영역에만 대입해 쟀다.

| 정답 IRM + 셸프 (전체) | +0.866 |

## 3. 잡음 제거기 재조정 (`retune/grid.csv`, 셸프 켬)
- 최고는 대역 하한 1–8 kHz −25 dB로 +0.006이었다. 나머지 10개 후보는 −0.04 ~ +0.001이었다.
- 대상: 대역별 하한, noise_beta, α, E8 혼합 비율.
- 대역별 β와 α를 함께 다시 맞춰도 표면이 평평하다.

## 4. 파일별 셸프 선택 (`shelf_oracle_subset.csv`)
- 31개 설정(시작 주파수 6개 × 깊이 5개 + 셸프 없음) 가운데 파일마다 최고를 고르는 정답 선택도 +0.099에 그쳤다.
- 깊이만 고르면 +0.051, 주파수만 고르면 +0.045였다. 실제 선택기는 이 상한의 일부만 얻는다.

## 5. 대역별 잔류 SNR 이퀄라이저 (`band_eq_subset.csv`)
- 정답 잔류 SNR로 9개 대역을 감쇠해도 +0.045, 추정 잔류 SNR로는 +0.004였다.

## 판단
- 채점기 보상을 이용하는 스펙트럼 모양 조정은 고정 셸프로 거의 다 얻었다. 남은 상한은 +0.05 ~ +0.10이다.
- 남은 큰 여지는 **음성 구간의 시간-주파수 이득 정확도**(+0.66)와 **위상**(+0.26)뿐이다. 둘 다 음성 구간에서 잡음과 음성을 더 정확히 가르는 추정이 필요하다.
- 지금까지의 비학습 추정 개선(C0, C2, TSNR, E8)은 단계마다 +0.01 ~ +0.04였다. 따라서 한 단계로 +0.4를 낼 비학습 방법은 이 측정에서 찾지 못했다.

## 7. 3점 벽의 원인 분해 (`gap_decomp_subset.csv`, `floor_comb_subset.csv`, `deep_floor_subset.csv`)
정답 신호를 한 요소씩 대입했다. 부분집합 기준 점수는 2.609다(셸프를 STFT 영역에서 적용해 2.626과 약간 다르다).

| 대입 | PESQ | 기준 대비 |
| --- | ---: | ---: |
| 잔류 잡음 전부 제거 (우리 이득 유지) | 3.964 | +1.35 |
| 음성 프레임의 잔류 잡음만 제거 | 3.601 | +0.99 |
| 700 Hz 미만 잔류 잡음만 제거 | 3.060 | +0.45 |
| 700 Hz 이상 잔류 잡음만 제거 | 2.787 | +0.18 |
| 음성 왜곡만 제거 (잔류 잡음 유지) | 2.928 | +0.32 |
| 이득이 IRM보다 큰 셀만 IRM으로 (덜 억압 교정) | 3.242 | +0.63 |
| 위 교정을 현재 하한 위에서만 | 2.847 | +0.24 |
| 정답 잡음 우세 셀(IRM < 하한)만 −10 dB 추가 감쇠 | 3.083 | +0.47 |
| 과억압 교정 (이득이 IRM보다 작은 셀만) | 2.668 | +0.06 |

현실 판별기의 결과:
- **하한 셀 심화 감쇠:** 하한에 붙은 셀 가운데 주변도 하한인 셀을 −6/−10 dB 더 줄이면 −0.08 ~ −0.27이었다.
  - 이렇게 고른 셀 가운데 실제로 IRM < 하한인 셀은 21–25%뿐이었다.
- **고조파 빗살 필터:** 실제 f0로는 최고 −0.005, 정답 f0로도 +0.03이었다. 유성 프레임이 15%뿐이다.
- **파일별 설정 선택:** 22개 설정 가운데 정답으로 고르는 상한도 +0.065였다.

### 결론
1. **3점 벽은 음성 구간 안의 잔류 잡음이다.** 무음 구간이나 음성 왜곡이 아니다. 특히 셸프가 닿지 않는 700 Hz 미만이 크다.
   - 저주파 잡음(바람, 구축함, 군용 차량, 공장, 교통)은 잡음 에너지의 77–98%가 700 Hz 미만이다.
2. **바로 원인은 하한이다.** 대역 하한(300 Hz–1 kHz −12 dB)이 잡음 우세 셀에 잡음을 −12 dB로 남긴다.
3. **하한을 못 낮추는 이유는 셀 판별이다.** 현재 추정기는 어느 셀이 잡음 우세인지 가르지 못한다. 하한에 붙인 셀의 3/4은 실제로는 음성이 의미 있게 섞인 셀이라, 하한을 낮추면 음성이 함께 깎인다.
4. **근본 원인은 정보 부족이다.** 단일 채널 에너지 기반 추정(γ, ξ, DD, Kalman)은 셀의 '양'만 본다. 잡음이 비정상(모든 종류에서 빈별 변동계수 ≥ 1)이면 셀마다 잡음인지 음성인지가 에너지만으로는 관측되지 않는다.
