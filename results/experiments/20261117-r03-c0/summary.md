# 3회차 Phase C0 실현성 진단 (기준 r03-base-s2)

점수를 바꾸지 않는 측정만 했다. 기본값과 denoiser 코드는 바꾸지 않았다.

## C0a·C0b. 파일 내 주기 잡음 (`periodic/`, `tools/diagnose_periodic.py`, Train 1296개)

반복 지연은 0.1–1.0 s로 잡았다. 3초에 주기가 3개 이상 들어가야 주기별 중앙값을 낼 수 있기 때문이다.

- **실제로 주기적인 파일:** 참 잡음의 반복 상관이 0.9 이상인 파일은 85개(6.6 %)다.
  - phone_dialing은 43개 모두 해당한다.
  - alarm_siren은 중앙값 0.67이다. 주기가 1 s를 넘는 경보가 많다. A6에서 1.5 s까지 보면 중앙값이 1.0이었다.
- **C1의 상한 (참 잡음으로 만든 템플릿을 빼고 현재 처리):**
  - 주기 파일만 적용하면 전체 1.994 → 2.062 (+0.067)다.
  - phone 2.99 → 3.80, alarm 1.73 → 2.07, 나머지 종류는 거의 변화가 없다.
- **Noisy만으로 검출 (C0a):**
  - 입력의 반복 상관은 중앙값 0.11이다. 음성이 반복 구조를 가린다.
  - 정밀도 95 %를 넘는 임계값은 재현율이 2–16 %이고, 주기가 맞는 비율은 0 %다.
  - 1 kHz 고역 통과를 해도 정밀도가 0.35 이하다.
  - Noisy 입력으로 만든 템플릿을 빼면(`sub_hat_dn`) 전체 1.61로 크게 손해다.
- **판정:** C1은 관문 미달이다 (상한 +0.15 이상, 정밀도 95 % 이상이 기준이었다). 우선순위에서 내린다. 전화음만 따로 다루는 파라메트릭 DTMF 차감은 C2 이후 선택 항목으로 남긴다.

## C0c·C0d. 하한과 사전 SNR 오차 (`xi/`, `tools/diagnose_xi.py`, Train 부분집합 350개)

잡음 PSD는 현재 처리의 최종 추정값이고, 저역 제한(300 Hz, −25 dB)은 항상 유지했다. 표는 부분집합 평균 PESQ-WB다.

| 사전 SNR \ 하한 | 현재 | −25 dB | −30 dB | −40 dB | 없음 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 참값 | 2.609 | 2.981 | 3.129 | 3.269 | 3.313 |
| 참값 × 칸별 무작위 오차 σ 4 dB | 2.600 | 2.964 | 3.108 | 3.239 | 3.278 |
| 참값 × 칸별 무작위 오차 σ 8 dB | 2.542 | 2.853 | 2.969 | 3.068 | 3.092 |
| **우리 DD** | **2.029** | 2.004 | 2.002 | 2.000 | 1.999 |
| 유성음 하모닉 칸만 참값, 나머지 DD | 2.102 | | 2.100 | | 2.100 |
| **음성 칸만 참값, 나머지 DD** | 2.068 | | 2.065 | | 2.062 |
| **무음성 칸만 참값, 나머지 DD** | 2.554 | | 2.991 | | **3.152** |

- **손실은 거의 전부 음성이 없는 칸에서 생긴다.**
  - 무음성 칸의 사전 SNR만 맞히고 하한을 없애면 2.03 → 3.15다.
  - 음성 칸만 맞히면 +0.04, 유성음 하모닉 칸만 맞히면 +0.07에 그친다.
- **오차의 크기보다 구조가 문제다.**
  - 칸마다 독립인 무작위 오차는 σ 8 dB여도 하한을 없애면 3.09다.
  - 우리 DD의 오차 RMS는 음성 칸 4.7 dB, 무음성 칸 10.6 dB다.
  - DD는 하한을 낮춰도 이득이 없다 (2.03 → 2.00).
  - 해석 (추정): DD는 관측 에너지(γ)를 따라간다. 그래서 잡음이 커지는 칸을 음성으로 오판한다. 이 오판은 시간·주파수로 몰려 있는 계통적 오차라서 하한을 낮추면 잡음이 그대로 드러난다.
- **판정:** 병목은 "칸마다 음성이 있는지"를 에너지가 아닌 단서로 가르는 문제다.
  - C2를 음성 존재 판정 기반의 깊은 억제로 다시 짠다.
  - 상한(무음성 칸 완벽 판정, 하한 없음)은 3.15다.
  - C3(하모닉 모델 사전 SNR)의 상한은 +0.07이라 우선순위를 내린다.
