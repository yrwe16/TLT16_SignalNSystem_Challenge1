## A4. 대역별 음성 보존과 잔류 잡음 (current, `oracle_train_bands.csv`)

| 대역 | 음성 레벨 변화 | 잔류 잡음 (에너지 가중) | 잔류 잡음 (칸 중앙값) | 설정된 LSA 하한 |
| --- | ---: | ---: | ---: | ---: |
| 0–325 Hz | −24.2 dB | −23.6 dB | −25.0 dB | 제한 −25 dB |
| 325 Hz–1 kHz | −1.2 dB | −4.4 dB | −6.8 dB | −12 dB |

| 4–8 kHz | −0.5 dB | −2.6 dB | −8.6 dB | −20 dB |

- 음성은 거의 그대로 보존된다.
- 반면 무음성 칸의 잡음은 중앙값으로도 −7~−9 dB밖에 줄지 않는다. 설정된 하한(−12~−20 dB)까지 거의 내려가지 않는다.
- 에너지 가중 잔류는 −3~−4 dB다. 큰 잡음 칸이 거의 그대로 통과한다는 뜻이다.
- SNR이 높을수록 덜 억제된다 (15 dB: 중앙값 −5.3~−7.6 dB).
- 무음성 칸은 깨끗한 칸 파워가 파일 최대보다 30 dB 아래인 칸으로 정의했다 (우리 선택).
- **해석 (추정):** DD 사전 SNR이 잡음 칸에서 과대 추정되거나, 잡음 PSD가 과소 추정되어 억제가 부족하다. Phase B의 B2(잡음 과대 추정 계수)와 사전 SNR 쪽 조치가 1순위다.

## A5. 채점기와 데이터 중복

- **채점기:** 강의 노트북(`data/noise_reduction_baselines.ipynb`)은 `pesq==0.0.4`의 `mode="wb"`를 쓴다. 우리 `.venv`도 pesq 0.0.4이므로 같은 척도다.
- **화자·발화:** Train 35명, Validation 5명이고, 공유하는 화자와 발화는 없다.
- **잡음 원본:**
  - Validation의 잡음 코드 61개는 모두 Train에 있다 (Train 88개: NOISEX-92 14, Nonspeech 74).
  - 잡음 파형 재사용을 확인하려고, Validation 각 파일의 잡음(noisy − clean)과 같은 코드의 Train 잡음 사이 최대 정규화 상호상관을 쟀다 (`noise_overlap_validation.csv`).
    - 중앙값은 0.97이고, 0.9를 넘는 파일이 68 %, 0.5를 넘는 파일이 87 %다.
    - Nonspeech 112개는 중앙값 0.99이고, NOISEX 52개는 중앙값 0.65다.
  - 즉 같은 잡음 녹음의 거의 같은 구간이 Train과 Validation에 반복된다. 히든 세트도 같을 가능성이 높다 (추정).
  - Train 잡음 파형을 템플릿으로 찾아 빼는 방식은 학습된 사전 금지(팀 규칙)와 대회 취지에 걸릴 수 있다. 조교 확인 전에는 쓰지 않는다.

## A6. 이득 구조와 잡음 반복성 (Train 부분집합 350개, `structure_probe_subset.csv`, 추가 측정)

평활한 참 잡음 PSD(λ)와 참 음성으로 구한 사전 SNR ξ = |S|²/λ를 넣고, 이득 규칙만 바꿔 PESQ-WB를 쟀다. 측정 스크립트는 저장소 밖 임시 파일이다 (`tools/oracle_decompose.py`와 같은 정의).

| 이득 | PESQ-WB | 0 / 5 / 10 / 15 dB |
| --- | ---: | --- |
| A. LSA + 현재 대역 하한 + 저역 제한 (os_both) | 2.665 | 1.79 / 2.31 / 2.73 / 3.29 |
| B. LSA + 저역 제한, 하한 없음 | 3.633 | 3.02 / 3.39 / 3.75 / 4.01 |
| C. LSA, 하한·저역 제한 없음 | 3.752 | 3.05 / 3.51 / 3.89 / 4.14 |
| D. Wiener ξ/(1+ξ), 하한 없음 | 3.324 | 2.56 / 3.01 / 3.42 / 3.84 |
| E. √Wiener, 하한 없음 | 3.435 | 2.73 / 3.20 / 3.53 / 3.87 |
| F. LSA, 순간 잡음 \|N\|² 사용 | 3.815 | 3.12 / 3.58 / 3.96 / 4.19 |
| G. 이상적 비율 마스크 | 3.664 | 2.92 / 3.40 / 3.82 / 4.08 |

- **사전 SNR이 정확하면 대역 하한(−12~−20 dB)이 약 1.0점을 깎는다** (A 2.67 → B 3.63).
  - 하한은 부정확한 ξ에서 생기는 음악성 잡음을 가리려는 장치다.
  - 그래서 ξ를 정확하게 만들고 하한을 낮추는 일을 함께 해야 한다.
- **잡음 통계(평활 λ)를 쓰는 것 자체는 한계가 아니다.** 순간 잡음을 아는 경우(F 3.82)와 차이가 0.06뿐이다.
- **잡음 PSD만 정확하고 ξ는 DD로 추정하면 2.18이다** (A2의 on_smooth). 즉 병목은 DD 사전 SNR 추정과 하한, 두 가지다.
- **파일 안 잡음 반복성:** 잡음(noisy − clean)의 정규화 자기상관 최대값을 0.1–1.5 s 지연에서 쟀다.
  - alarm_siren, phone_dialing, clap은 중앙값 1.000이다. 파일 안에서 같은 잡음 파형이 주기적으로 반복된다.
  - machine 0.53, destroyer_operations 0.42는 부분적으로 반복된다. NOISEX 계열은 중앙값 0.21이다.
  - 부분집합 전체에서 r > 0.9인 파일이 15 %다.
