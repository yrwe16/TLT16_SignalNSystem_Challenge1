# R3-7 CASA 진폭 변조 단서 가중 (기준 r03-base-s4)

## 동기
`20261117-r03-levers2/summary.md` 7절에서 3점 벽의 원인을 확인했다.
- **잔류 잡음:** 3점 벽은 음성 프레임 안의 잔류 잡음이다.
- **판별 실패:** 현재 추정기는 잡음 우세 셀을 가르지 못한다.

## 단서 판별력 (`cue_auc_subset.csv`, 부분집합 350개)
- **대상 셀:** 음성 프레임, 80 Hz–1 kHz.
- **정답 라벨:** 잡음 우세 셀을 IRM < 하한으로 정했다 (셀의 21%).

| 점수 | AUC | 하한 셀 안 | 하한 위 셀 안 |
| --- | ---: | ---: | ---: |
| 현재 이득 G | 0.595 | – | – |
| 음절 속도 변조 세기 | **0.674** | 0.653 | 0.648 |
| 국소 상승 (0.5 s 평균 대비) | 0.576 | 0.584 | 0.584 |
| 인접 빈 포락선 상관 | 0.570 | 0.561 | 0.548 |
| 공통 시작 | 0.522 | 0.497 | 0.536 |
| 스펙트럼 첨예도 | 0.428 | 0.464 | 0.448 |

변조 단서만 현재 이득과 독립된 정보를 준다. 이득 수준별로 나눠도 AUC가 약 0.65였다.

## 방법 (`pipeline.casa_mod_weight`)
1. **변조 성분:** 잡음 섞인 입력의 빈별 로그 파워에서 62.5 ms 이동평균과 250 ms 이동평균의 차(대역 통과)를 구한다.
2. **변조 세기:** 이 차를 320 ms 동안 RMS로 평균한다.
3. **가중:** 출력 이득에 clip(변조 / 파일 중앙값, 하한, 1)^지수를 곱한다. 80 Hz 미만은 제외한다.
4. **출처:** 진폭 변조 단서라는 착상은 Hu & Wang, IEEE TNN 15(5), 2004에서 왔다 (원문 미확인). 특징과 규칙은 우리 선택이다. 학습 요소는 없다.
