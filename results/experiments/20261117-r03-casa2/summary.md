# R3-8 CASA 추가 단서 결합 (기준 r03-base-s5)

## 단서 선별 (`extra_cues_subset.csv`, 부분집합 350개)
- **방법:** 현재 출력(변조 가중 포함)에 단서 가중 clip(단서/파일 중앙값, 하한, 1)^k를 하나씩 곱했다.
- **기준:** 셸프를 STFT 영역에서 적용해 2.6794다.

| 단서 | 최고 변화 |
| --- | ---: |
| 느린 변조 (약 1–4 Hz) | +0.015 |
| 바닥 대비 상승 (1 s 최솟값 대비) | +0.011 |
| 프레임 조화도 (정규화 자기상관) | +0.009 |
| 주파수 확산 변조 (±4 빈 평균) | −0.018 |
| 빠른 변조 (약 4–16 Hz) | −0.029 |
| 광대역 공변조 상관 | −0.033 |

## 결합 (`combo_cues_subset.csv`)
| 결합 | 변화 |
| --- | ---: |
| 느린 변조 × 조화도, k 0.5 | **+0.025** |
| 세 단서 모두, k 0.35 | +0.022 |
| 느린 변조 × 상승, k 0.25 | +0.020 |

상승 단서는 느린 변조와 정보가 겹쳐, 함께 쓰면 더 얻는 것이 없었다.

## 파이프라인 (`pipeline.casa_extra_weight`)
- **느린 변조:** 잡음 섞인 입력의 빈별 로그 파워에서 125 ms − 500 ms 이동평균 차를 구하고, 640 ms RMS로 평균한다.
- **조화도:** 변조 가중 직후 출력의 프레임 조화도다. 40 ms 창에서 지연 2.5–16.7 ms 범위의 정규화 자기상관 최댓값을 구하고, 3프레임 평활한다.
- **적용:** 두 가중을 곱해 80 Hz 이상에 적용한다.
- **출처:** 특징과 규칙은 우리 선택이고, 학습 요소는 없다.

## 결과
- **부분집합 격자** (`subset/grid.csv`, 기준 2.6789):
  - 느린 0.5 / 조화 0.5: **2.7051**
  - 나머지 5개 후보: 2.7012 ~ 2.7041
- **Train 전체:**
  - 0.5 / 0.5: **2.6920** (+0.018)
  - 0.5 / 0.75: 2.6911
- **Validation:** **2.6518** (+0.024).
- **채택 검사:** compare_runs 조건이 모두 통과했다.
- **좋아진 종류:** 전화 다이얼 +0.07, 경보 +0.021, 바람 +0.021, 항공기 +0.018, 기계 +0.016.
- **가장 나빠진 파일:** 경보 4개가 −0.18 ~ −0.41이었다. 사이렌의 조화성 때문에 잡음 프레임의 조화도가 높게 나오는 것으로 추정한다.
